  • Open admin chat dashboard

🔍 Debug Information
Testing Steps:
  1. Open two browser windows/tabs
  2. Window 1: Go to homepage and click 💬 button (Customer)
  3. Window 2: Go to /admin/chat (Admin)
  4. Test Customer → Admin: Send message from customer, verify admin sees it
  5. Test Admin → Customer: Send message from admin, verify customer sees it
Debug Console:

Open browser console (F12) to see debug logs:

  • ✅ WebSocket Connected
  • 📡 Received message on /topic/public
  • 📨 Received message: [message object]
  • ✅ Displaying message
Backend Logs:

Check your Spring Boot console for:

  • 📨 Received message from [sender] ([type]): [content]
  • 📡 Broadcasting message to /topic/public
  • ✅ Message broadcasted successfully
